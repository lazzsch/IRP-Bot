IRP Bot V3 - Quick Install Guide

Choose the easiest option for your users. Use Chrome Web Store first (when approved), and keep Userscript Lite as a fallback.

Option A (Recommended)

Chrome Store (Unlisted)

Best for non-technical users once approved.

  1. Open the private Chrome Web Store link you share.
  2. Click Add to Chrome.
  3. Pin the extension in the toolbar.
  4. Open https://portal.irishimmigration.ie/en/reschedule_appointment/.
  5. Complete setup wizard and start the bot.
Option B (Fast Fallback)

Tampermonkey + Userscript Lite

Use while Chrome Store review is pending.

  1. Install Tampermonkey from Chrome Web Store.
  2. Open the script raw URL:
    https://raw.githubusercontent.com/lazzsch/IRP-Bot/main/userscript/IRP-Bot-Lite.user.js
  3. Click Install in Tampermonkey.
  4. Open /en/reschedule_appointment/ page.
  5. Configure minimum date and booked date, then start.

Important Rules

  1. Use the portal in English flow (/en/) for reliable behavior.
  2. Keep minimum date and booked date updated.
  3. If a better date is found, confirm your configured automation options.
If setup looks wrong, reload the page and run setup again before starting.
