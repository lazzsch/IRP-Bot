IRP Bot V3 - Guia Rápido de Instalação

Escolha a opção mais simples para seus usuários. Use a Chrome Web Store primeiro (quando aprovada) e mantenha o Userscript Lite como plano B.

Opção A (Recomendada)

Chrome Store (Unlisted)

Melhor para usuários leigos quando já estiver aprovado.

  1. Abra o link privado da Chrome Web Store que você compartilhou.
  2. Clique em Adicionar ao Chrome.
  3. Fixe a extensão na barra do navegador.
  4. Abra https://portal.irishimmigration.ie/en/reschedule_appointment/.
  5. Conclua o assistente inicial e inicie o bot.
Opção B (Rápida)

Tampermonkey + Userscript Lite

Use enquanto a revisão da Chrome Store estiver pendente.

  1. Instale o Tampermonkey na Chrome Web Store.
  2. Abra o URL raw do script:
    https://raw.githubusercontent.com/lazzsch/IRP-Bot/main/userscript/IRP-Bot-Lite.user.js
  3. Clique em Install no Tampermonkey.
  4. Abra a página /en/reschedule_appointment/.
  5. Configure data mínima e data marcada, depois inicie.

Regras importantes

  1. Use o portal no fluxo em inglês (/en/) para maior estabilidade.
  2. Mantenha data mínima e data marcada atualizadas.
  3. Quando surgir data melhor, confirme as opções de automação que você ativou.
Se a configuração parecer errada, recarregue a página e execute o setup novamente antes de iniciar.
